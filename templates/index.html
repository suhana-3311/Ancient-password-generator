PROJECT CONCEPT

What the project actually does

The application does not treat ancient systems as a replacement for modern cryptography. They provide meaningful, topic-specific input; secure randomness supplies unpredictability.

ANCIENT KNOWLEDGE SYSTEMS

Three ideas, one focused application

01

Sanskrit Words

Meaningful Sanskrit-inspired words are used as a human-readable starting point. Examples in this application include:

{% for word, meaning in sanskrit_words.items() %} {{ word.title() }} · {{ meaning }} {% endfor %}
A recognizable word is only an input. It is never presented as secure by itself.
02

Katapayadi

Katapayadi is a traditional Indian mnemonic/numerical system in which consonants are associated with digits. This project uses a clearly documented Roman-transliteration demo table.

Ka Kha Ga Gha1 2 3 4
Cha Chha Ja Jha6 7 8 9
Pa Pha Ba Bha Ma1 2 3 4 5
Ya Ra La Va1 2 3 4
Sha Sa Ha5 7 8

The generator ignores vowels for this consonant-to-digit step and reverses the collected digits to demonstrate the traditional right-to-left number reading convention.

03

Bhuta Sankhya

Bhuta Sankhya expresses numbers through familiar objects or concepts. The project uses selected examples to create a second traditional numerical input.

{% for name, value in bhuta_sankhya.items() %}
{{ name }}{{ value }}
{% endfor %}
Traditional associations can vary by source and context. The application therefore displays its selected mappings explicitly instead of hiding them.

IMPORTANT EXAMPLE

Agni + Vedas → traditional input + secure randomness

For example, Agni is selected as the Sanskrit-inspired word and Vedas → 4 supplies a Bhuta Sankhya value. The Katapayadi step produces a numerical component. The final password is then shuffled and strengthened with unpredictable characters from Python's secrets module.

AGNI+Katapayadi digits+Vedas = 4+secrets→STRONG PASSWORD
SECURITY PRINCIPLE

Ancient inspiration. Modern unpredictability.

The educational mapping makes the project relevant to the Ancient Knowledge Systems topic. It is the cryptographically secure random generation that prevents the final password from being a predictable transformation of a known word.

Python Flask handles the web backend.
HTML + CSS + Bootstrap provide the interface.
secrets provides security-oriented randomness.
Strength checks evaluate length and character variety.
